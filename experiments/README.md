# Experiments

Small, throwaway tries — one folder per idea, numbered in order:

```
experiments/
├── 01-hello-llm/
├── 02-structured-output/
└── ...
```

Each folder gets a `README.md`:

```markdown
# NN - <idea>

**Goal:** what I wanted to find out
**How to run:** commands
**What I learned:** 2–5 bullets
```

When an experiment turns into something worth keeping, move it to `projects/`.
